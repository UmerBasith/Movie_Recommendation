# 🎬 Movie Recommendation System

A content-based movie recommender built with **Flask** and **Python** that suggests movies based on similarity tags (plot, genres, cast, crew).  
It uses **Cosine Similarity** and Natural Language Processing (NLP) to analyze the TMDB 5000 Movies dataset and find the best matches.  
The frontend is designed with **Tailwind CSS**, featuring a responsive UI, smooth animations, and real-time poster fetching via the **TMDB API**.  
Robust features include case-insensitive search, automatic space handling, and smart fallback images for missing posters.  
To run the project, install dependencies (`pip install flask flask-cors pandas scikit-learn requests`) and execute `python app.py`.
